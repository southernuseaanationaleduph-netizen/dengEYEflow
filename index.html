DengEYE D.I.S — Full App Flow

User opens DengEYE app

Resident, BHW, or Barangay Official — selects role on first launch. Location permissions requested.

Home screen: live hotspot map

Real-time dengue risk map loads. Color-coded zones (green → red) based on aggregated data from all modules.

↓

4 core modules

TANAW-KLIMA

Environmental risk prediction

1User inputs temperature + humidity
2LSTM model processes time-series data
3Risk forecast generated (24–72 hrs)
4Risk intensity overlaid on hotspot map
LSTM model time-based forecast dynamic map layer
PUGAD-SIYASAT

Breeding site detection

1User opens camera — continuous scan starts
2YOLO-based CNN auto-detects sites in real-time
3Bounding boxes drawn on detected objects
4GPS coordinates auto-logged + map tagged
5GLINT mode: light-reflection scan for dark areas
6TUSOK points awarded only on BHW verification
YOLO-CNN GLINT mode TUSOK accuracy points
TUKLAS

Dermatoscopic diagnostic

1User captures rash via dermatoscope or phone cam
2CNN model classifies cutaneous rash pattern
3Preliminary risk result shown (screening only)
4If suspected positive: GPS logged, alert triggered
5Case added to community risk map
6Nearest RHU routing initiated automatically
CNN classifier secondary prevention geo-alert
BANTAY-BAYANIHAN

Community reporting

1Resident files daily health update or symptom report
2AI chatbot triages in Filipino/dialect
3BHW verifies report → elevates to RHU if needed
4Peer-to-peer Kumarites awareness sharing
5Offline queue: reports sync when back online
6TUSOK score updated per verified report accuracy
BHW integration AI chatbot offline-first Kumarites network

Score calculation

+Report submitted → pending (no points yet)
✓BHW verifies report as real → +10 pts
✗BHW flags as false positive → −5 pts penalty
★Site resolved/eliminated → bonus +5 pts

Leaderboard shows accuracy rate, not volume

110 reports, 8 verified = 80% accuracy, 80 pts
2Spamming reports lowers your accuracy score
3Rank titles: Baguhan → Tracer → Manlalaban → Bayani
